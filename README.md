<h3 align="left">Features:</h3>  

- Detects as a standard keyboard  
- Works on any OS  
- ```10``` slots for macro, ```~13000``` inputs per each slot  
- ```No Driver``` required
- Easy 6 Wire assembly  
- Full control direcly from keyboard
